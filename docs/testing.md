# Testing

```bash
cd backend && php artisan test
```

Covered:

- Availability
- Double-booking prevention
- Hold expiry releasing inventory
- Room blocks
- Coupons
- Payment confirm
- Duplicate callback
- Incorrect amount
- Client price tampering
- Role permissions

Frontend: `npm run lint` and `npm run build`. Exercise booking on 375px and 1280px in a browser before launch.
